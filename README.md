# 🚀 Page Pulse - Website SEO & Performance Analyzer

Page Pulse is a web-based website auditing tool that analyzes any URL and provides a detailed SEO and performance report.

It fetches the webpage, extracts important HTML information, measures performance metrics, and displays the results through a clean dashboard interface.

---

# ✨ Features

## Website Analysis

- ✅ URL validation
- ✅ HTTP status code detection
- ✅ Response time measurement
- ✅ Page title extraction
- ✅ Meta description extraction
- ✅ H1 heading count
- ✅ Images missing ALT attribute detection
- ✅ Approximate word count calculation


## Error Handling

Handles:

- Invalid URLs
- Missing URL input
- Website timeout
- Non-HTML responses
- Failed website requests


## Frontend Dashboard

- Modern responsive UI
- Color-coded metric cards
- SEO score calculation
- Loading animation
- Error messages
- Clean user experience
